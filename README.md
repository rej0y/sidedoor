## Software Description

Our team plans to develop a web-based application called a “Professor Directory” that helps college students quickly find and connect with faculty members. The application will allow users to browse professors by department, search by name, and sort results based on different criteria such as alphabetical order.

Each faculty listing will display key information including the professor’s name, department, office location, and office hours. In addition to the list view, the application will feature an interactive campus map that visually displays office locations using color-coded markers by department. This allows students to easily understand where professors are located and navigate campus more efficiently.

The goal of this application is to simplify the process of finding professors and attending office hours by combining directory information with spatial navigation in a single, user-friendly interface. This is especially useful for new students or those taking classes across multiple departments.

The system will use a data storage solution (such as a database) to manage faculty information, including names, departments, office locations, and schedules. Core features of the minimum viable product will include searching, filtering by department, viewing professor details & schedules, and displaying office locations on the campus map.

During Sprint 1 and 2, our team will continue refining the prototype, researching user needs, and determining which features are essential for the minimum viable product. We will use our current Figma design as a foundation to test layout, usability, and overall user experience before beginning full development.
